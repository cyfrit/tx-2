# Local catalog of original TX-2 sources

Collection date: 2026-11-10. This catalog is generated by `tools/build_source_catalog.py`. Commands and code paths are relative to the repository root.

Saved **60 PDFs totaling 5,346 pages, plus three reference posters**.
Scans and posters total 628.4 MB. Counts include alternate scans and revisions of the same work.
Modern collection catalog pages, metadata, and OCR attachments are excluded from the original-document PDF count.

See [HARDWARE-READING.md](HARDWARE-READING.md) for the architecture and timing analysis based on close reading.

## Collection scope and sources

Scans come from public Bitsavers mirrors, Internet Archive, RCS/RI, and the Computer History Museum official GitHub repository.
Each entry retains its original source, download URL, SHA-256, file size, page count, and extracted-text path.
The machine-readable catalog is [manifest.json](../references/catalog/manifest.json), with a tabular version in [bibliography.csv](../references/catalog/bibliography.csv).

The collection includes all PDFs in the Bitsavers TX-2 directory and its RCS/RI subdirectory, plus related Division 6 hardware documents,
early laboratory progress reports, 13 Graphics semiannual reports, and both parts of the original Sketchpad listing.
The collection also records [82 progress-report catalog links](../references/catalog/progress-report-inventory.json) for locating later general reports that have not been downloaded.

## Reading and revision notes

- Multiple scans of the three Technical Manual volumes are retained to recover missing figures and compare scan differences.
- Native PDF text and Internet Archive OCR are stored separately. Eight supplemental OCR files were checked against the original PDF MD5 and page count.
- A text layer enables searches. Inversion bars, superscripts, subscripts, phases, and connections in figures still require visual checking.
- File names and catalog dates may identify the start of a compilation. For example, `TX2-Memos-Display_196401` includes documents from October 1964 and January 1965.
- Bound handbooks contain replacement pages from different dates. The scan named for 1963 includes a 1964 APEX configuration table.
- Internet Archive search metadata dated two 1958 memos to 1919. Covers and dates within pages determine chronology.

Search examples:

```sh
python3 tools/search_sources.py 'memory overlap' --source LM-44v2 --limit 5
python3 tools/search_sources.py 'CONFIGURATION|FRACTURE' --source TX-2_TechManVol2 --limit 10
```

Each result reports the actual PDF page number. Check the scan for printed page numbering.
